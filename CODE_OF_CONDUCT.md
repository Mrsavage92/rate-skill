# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), v2.1.

In short: be respectful, assume good faith, and keep disagreement about ideas
- not people. Harassment, personal attacks, and discriminatory language or
conduct are not tolerated.

Report a violation the same way as a security issue - see
[SECURITY.md](SECURITY.md) - or via a GitHub issue if the report itself
doesn't need to be private.
